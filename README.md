# fraq-plugin-doudizhu

基于 Fraq 的群聊斗地主人机插件。每个房间由 1 名真人和 2 名人机组成，牌局在群聊中进行，手牌和出牌结果使用 `image/` 目录中的牌面图片合成后发送。

## 环境要求

- Node.js `>=22`
- Fraq `>=1.1.0`
- 能够安装 `sharp` 原生依赖的运行环境

## 安装

使用 pnpm 安装：

```bash
pnpm add fraq-plugin-doudizhu
```

也可以使用 npm：

```bash
npm install fraq-plugin-doudizhu
```

在 Fraq 项目的 `fraq.yml` 中启用插件，并按需调整配置：

```yaml
configVersion: 1
fraqVersion: 1.1.0

plugins:
  doudizhu:
    maxRooms: 2
    turnTimeoutMs: 60000
```

如果项目使用 `versions.yml` 锁定插件版本，可以写成：

```yaml
doudizhu: 0.1.0
```

配置项：

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `maxRooms` | `2` | 每个群允许同时进行的最大房间数 |
| `turnTimeoutMs` | `60000` | 单次操作超时毫秒数，超时后直接结束牌局并释放房间 |
| `imageDirectory` | `image/` | 可选的自定义牌图目录 |

插件只处理群聊消息，指令前缀由 Fraq 的 activation 配置决定。

## 群聊指令

开始前先注册：

```text
注册
开始斗地主
```

对局指令：

```text
明牌
叫地主
叫地主 0
叫地主 1
叫地主 2
叫地主 3
不叫
抢地主
加倍
超级加倍
不加倍
出牌 3 3 3 8
要不起
```

`叫地主` 不带数字时等同于叫 `3` 分；`抢地主` 会按当前最高分自动提交下一档。`出牌` 后可使用空格、逗号或顿号分隔牌面。

支持的牌面包括 `3` 至 `10`、`J`、`Q`、`K`、`A`、`2`、`小王` 和 `大王`。

## 对局规则

- 每个群独立维护房间池，默认最多同时运行 2 个房间。
- 同一个 QQ 在同一个群中只能加入一个房间；每个房间始终只有一名真人。
- 每局使用 54 张牌，三名玩家各 17 张，剩余 3 张作为底牌。
- 连续三轮无人叫地主时，系统会随机选择一名玩家成为地主。
- 机器人会自动完成叫地主、加倍和出牌，直到轮到真人操作。
- 任意一次操作超过 `turnTimeoutMs` 未完成，牌局立即结束，房间被回收并向群发送通知。
- 真人出完牌后牌局结束，房间会被释放。

牌型解析和比较支持：

- 单牌、对子、三张
- 三带一、三带二
- 顺子、连对
- 飞机、飞机带单、飞机带对
- 炸弹、王炸

机器人当前主要生成单牌、对子、三张、顺子、连对、炸弹和王炸，属于基础出牌策略，尚不是完整的高阶 AI。

## 图片牌面

牌图资源位于插件包的 `image/` 目录。插件使用 `sharp` 将牌图缩放并横向叠放，生成 `base64://` 图片，通过 Fraq 的 `seg.image` 发送；相同顺序的手牌会使用内存缓存，减少重复合成开销。

## 本地开发

```bash
pnpm install
pnpm test
pnpm build
pnpm check
```

构建产物：

- `dist/index.mjs`
- `dist/index.d.mts`

## 当前限制

- 注册信息和房间状态保存在内存中，进程重启后会清空。
- 当前仅支持一名真人和两名机器人的人机模式。
- 暂无真人 PK、观战和跨群匹配功能。
- 机器人使用基础策略，复杂牌局的决策能力仍在完善中。
